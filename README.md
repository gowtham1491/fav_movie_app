# 🎬 Favorite Movie App

A full-stack web application that allows users to manage and track their favorite movies and TV shows.

## 🚀 Features
- Add new movies or TV shows with details like:
  - Title, Type, Director, Budget, Location, Duration, Year/Time
- View all entries in a dynamic, scrollable table.
- Backend powered by **Node.js + Express + MySQL**.
- Frontend built using **React.js** with responsive design.
- RESTful API integration between frontend and backend.

## 🧩 Tech Stack
**Frontend:** React.js, CSS  
**Backend:** Node.js, Express.js  
**Database:** MySQL  
**Other Tools:** Git, GitHub, Postman, npm
