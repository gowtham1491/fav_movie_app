# 🎬 Favorite Movie & TV Show App

A full-stack web application that allows users to manage their favorite movies and TV shows.  
Users can **add, edit, and delete** entries easily with a clean and interactive UI.

---

## 🚀 Features

- ➕ Add new movies or TV shows  
- ✏️ Edit existing records directly in the table  
- 🗑️ Delete entries instantly  
- 🎚️ Dropdown menu for selecting type (Movie / TV Show)  
- 📋 Displays all records in a table  
- 🔄 Live updates after each add/edit/delete  
- 💾 Data stored in **MySQL** using **Express.js backend**

---

## 🧩 Tech Stack

| Layer | Technology |
|-------|-------------|
| Frontend | React (Create React App), Axios, CSS |
| Backend | Node.js, Express.js |
| Database | MySQL |
| Others | CORS, Body-Parser |
